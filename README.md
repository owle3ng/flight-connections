Перелёты с пересадками Учебный проект на Java(jdk 24 стоит) для 1 аттестации. Реализован базовый уровень задачи № 23.

Возможности аэропорты с часовыми поясами; местное расписание рейсов и расчёт длительности через Instant и Duration; бронирование и перечисление классов обслуживания;

Основные решения Расписание хранится как LocalDateTime в местном времени соответствующего аэропорта. Сравнение моментов и расчёты длительности выполняются через Instant и Duration.
